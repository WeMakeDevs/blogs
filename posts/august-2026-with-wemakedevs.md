This month, we’re bringing together developers through hackathons, hands-on challenges, technical meetups, and networking events across different cities and online. There’s something for people who want to build an AI agent, experiment with web scraping, improve their code, work on infrastructure, or simply meet other people building with technology.

From short challenges to week-long hackathons and in-person community events, here’s what we have planned for August.

## The Zerops Challenge - August 8–9

![Zerops Challenge](images/august-2026-with-wemakedevs/zerops-challenge.webp)

[The **Zerops Challenge**](https://www.wemakedevs.org/hackathons/zerops) kicked off on August 8, giving builders 48 hours to turn their ideas into working, deployed products. The online challenge brought together builders from across the globe, with participants building solo and using Zerops to take their projects from concept to live applications.

The challenge saw **1,500+ registrations** and **250+ project submissions** by the time it wrapped up on August 9, with participants from **36 countries** taking part. Participants built everything from AI products and developer tools to SaaS applications and real-time platforms, showcasing what they could create and deploy on Zerops in just one weekend.

#### Main Track Winner

![Main Track Winner](images/august-2026-with-wemakedevs/main-track-winner.webp)

The Best Overall Project went to [Deplot AI](https://web-2a39-3000.prg1.zerops.app), an autonomous platform engineer built for Zerops. Deplot lets developers paste any GitHub repository and automatically analyzes the stack, designs the architecture, generates the required `zerops.yaml`, and deploys the application into an isolated sandbox. It then goes beyond deployment by monitoring live health, diagnosing incidents in plain English, and helping fix and redeploy affected services.

Repository Link: https://github.com/maannaan/Deplot

## Into the Scrape-Verse Hackathon - August 17–23

![Scrape Verse](images/august-2026-with-wemakedevs/scrape-verse.webp)

[Into the Scrape-Verse Hackathon](https://www.wemakedevs.org/hackathons/scrape-verse) is live! Running from August 17 to 23, this online hackathon with Bright Data is challenging developers, builders, and AI engineers to create self-healing web scrapers using Bright Data Scraper Studio.

The hackathon is open-ended, so you can build anything that turns websites into structured data. There are plenty of directions you can take the project. Build a simple one-prompt scraper, turn scraped data into a RAG knowledge base, create a competitive intelligence pipeline, build a keyword-powered research agent, or make self-healing the core of your project. The key is to show that your scraper can build, run, recover, and keep working when the web changes.

## Zero Downtime Hackathon

![Zero Downtime](images/august-2026-with-wemakedevs/zero-downtime.webp)

**August 22 | 9:00 AM – 6:00 PM GMT-7 | San Francisco**

Join us on **August 22 at Bright Data in San Francisco** for the **Zero Downtime Hackathon**, where you’ll get a chance to build resilient applications and pipelines that can collect data, recover from failures, and stay observable in production.

The challenge brings together three tools:

* **[Port](https://www.port.io)** to plan your project, track risks, tasks, and services.
* **[Bright Data Scraper Studio](https://brightdata.com/products/web-scraper/studio)** to extract web data and automatically repair scrapers when websites change.
* **[SigNoz](https://signoz.io)** to monitor your application with logs, metrics, and traces.

Build a working app, automated pipeline, or agentic workflow using **Claude Code, Cursor, or Codex**, and connect all three tools into one complete lifecycle.

### 🏆 Prizes

The **Grand Prize** is an **NVIDIA DGX Spark AI Supercomputer worth $5,000** for the best full-stack integration of all three tools.

There are also three track prizes, with **Keychron keyboards worth $120 for every member of each winning team**:

* Best Port Integration
* Best Bright Data Scraper Studio Integration
* Best SigNoz Integration

Registration Link: https://luma.com/zero-downtime

## ROAST MY PR CTF - Code, Bugs, and a Mac Mini

![Roast My PR](images/august-2026-with-wemakedevs/roast-my-pr-night.webp)

**August 26 | 5:00 PM – 9:00 PM GMT-7 | San Francisco**

Join us at GitHub HQ in San Francisco for Roast My PR CTF, an evening focused on writing cleaner, smarter, and more reliable code with engineers from Qodo Dev Community, [GitHub](https://github.com), [Port](https://www.port.io), and [OpenAI](https://openai.com).

The challenge is simple: you’ll receive repository issues containing hidden bugs, use Qodo to identify them, submit a pull request with your fix, and try to get it merged. During the live review, submitted PRs will be reviewed on the big screen based on code structure, logic, edge cases, and overall quality.

**The best merged PR of the night wins an Apple Mac mini.**

Registration Link: https://luma.com/roastpr
Capacity is limited, so RSVP only if you plan to attend in person.

## The Agent Harness Hackathon - August 22–30

![Agent Harness](images/august-2026-with-wemakedevs/agent-harness.webp)

**August 22–30 | Online + San Francisco**

[The Agent Harness Hackathon](https://www.wemakedevs.org/hackathons/trueforge), powered by [TrueFoundry](https://www.truefoundry.com), challenges you to build real-world agents using TrueForge, an open-source agent harness.
